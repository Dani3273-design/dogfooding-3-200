# 产品评分分析程序

## 项目简介

这是一个基于Python的产品评分数据分析程序，用于对电商产品的用户评分数据进行统计分析，并生成可视化的PDF分析报告。

## 功能特性

### 1. 数据分析功能
- **评分概率统计**：计算用户评分与不评分的概率分布，输出饼状图
- **评论意愿分析**：针对已评分的数据，按评分级别统计评论文本长度（0-10字、10-30字、30字以上）的分布
- **产品评分排行**：计算各产品的平均评分，列出评分前4的产品，其余合并为"其他产品"，输出饼状图

### 2. 输出功能
- 生成中文PDF报告，包含数据概览和所有可视化图表
- 重复运行时直接覆盖PDF文件，无需手动删除

### 3. 数据格式支持
处理包含以下字段的CSV数据：
- `rating`：评分（1-5分表示已评分，0表示未评分）
- `product_id`：产品ID
- `product_name`：产品名称
- `review_text`：评论文本（最多100字）
- `purchase_record`：消费记录编号
- `purchase_date`：购买日期

## 技术栈

- **Python 3.9+**
- **数据处理**：polars - 高性能数据处理库
- **图表可视化**：plotly - 交互式图表库，支持饼状图等多种图表
- **PDF生成**：reportlab - 专业PDF生成库，支持中文显示

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 生成测试数据

```bash
python test/generate_test_data.py
```

测试数据生成规则：
- 自动随机选择年月（2023-2025年）
- 生成600条评分数据
- 每条消费记录对应一条评分数据
- 15%概率用户不评分（评分为0，评论文本为空）
- 85%概率用户评分（1-5分），60%概率附带评论文本（最多100字）
- 数据符合基本规律，不存在全5分或全0分的产品

### 3. 运行分析程序

```bash
python main.py
```

运行后将在 `report/` 目录下生成 `product_rating_report.pdf` 报告文件。

## 代码规范

- 采用蛇形命名法（snake_case）
- 所有print输出文本使用英文
- 关键函数和API添加中文注释
- 模块间职责分离，代码易于维护和扩展

## 输出报告说明

生成的PDF报告包含以下内容：

1. **数据概览**：总记录数、有效评分数、平均评分、产品总数
2. **用户评分分布**：评分/未评分比例饼状图
3. **评论长度意愿分析**：1-5星各评分级别的评论文本长度分布饼状图
4. **产品平均评分排行**：Top4产品平均评分饼状图和详细表格

## 注意事项

- 程序自动处理中文字体，确保PDF无乱码、方块或文字重叠问题
- 临时图表文件会在PDF生成后自动清理
- 重复运行会直接覆盖PDF报告文件
