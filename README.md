# 产品评分分析程序

## 项目简介

本程序用于分析产品评分数据，生成包含可视化图表的分析报告。程序能够处理用户评分数据，分析评分分布、评论长度分布以及各产品的平均评分情况，最终输出为中文PDF报告。

## 功能特性

### 1. 数据处理能力
- 支持产品评分数据（评分1-5分、产品ID、产品名称、评论文本、消费记录）
- 使用Polars进行高效数据处理

### 2. 可视化分析
- **评分意愿分布饼状图**：展示用户选择评分与不评分的比例
- **评论长度分布饼状图**：针对每个评分等级（1-5分）单独分析评论长度分布
  - 0-10字：简短评论
  - 10-30字：中等长度评论
  - 30字以上：详细评论
- **产品平均评分饼状图**：展示评分前4的产品及平均评分，其他产品合并统计

### 3. 报告输出
- 输出格式：中文PDF报告
- 报告包含数据概览、图表分析、详细数据表
- 支持重复运行，自动覆盖旧报告

## 安装与运行

### 环境要求
- Python 3.9+
- 支持macOS/Linux/Windows系统

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行程序

```bash
python main.py
```

程序运行后会：
1. 自动生成600条测试数据（随机年份、月份）
2. 进行数据分析处理
3. 生成PDF报告并保存到 `report/` 目录

## 测试数据说明

测试数据生成器会创建符合以下规则的模拟数据：

- **数据量**：600条消费记录
- **时间范围**：随机年份（2022-2024年）、随机月份
- **产品数量**：10个不同产品
- **评分规则**：
  - 约70%的用户会进行评分（1-5分）
  - 约30%的用户选择不评分（评分为0）
  - 不同产品有不同的评分分布倾向，确保不存在全5分或全0分的产品
- **评论规则**：
  - 评分用户可选填评论（限制100字以内）
  - 不评分用户评论为空
  - 评论长度和评分高低有一定相关性

## 技术说明

### 技术栈
- **数据处理**：Polars（高性能DataFrame库）
- **图表生成**：Plotly（交互式图表库）
- **PDF生成**：ReportLab（PDF文档生成库）

### 代码规范
- 采用蛇形命名规范（snake_case）
- 程序输出文本使用英文
- 代码注释使用中文

### 中文字体支持
程序会自动检测并注册系统中的中文字体：
- macOS：苹方(PingFang)、黑体(STHeiti)、冬青黑体(Hiragino Sans GB)
- Linux：文泉驿正黑(WenQuanYi Zen Hei)
- Windows：黑体(SimHei)、宋体(SimSun)、微软雅黑(Microsoft YaHei)

## 输出报告示例

生成的PDF报告包含以下内容：

1. **封面与概览**
   - 报告标题与统计周期
   - 数据概览表（总记录数、已评分、未评分、评分率）

2. **用户评分意愿分布**
   - 饼状图展示评分与不评分的比例

3. **各评分等级评论长度分析**
   - 5个子图分别展示1-5分评级的评论长度分布
   - 包含说明文字解释不同长度评论的特征

4. **产品平均评分排名**
   - 饼状图展示前4产品与其他的平均评分
   - 详细数据表列出产品名称、平均评分、评分数量

## 注意事项

1. 首次运行可能需要下载Plotly的Kaleido组件用于图片导出
2. 如果系统中没有中文字体，PDF中的中文可能显示为方框或乱码
3. 程序会覆盖已存在的报告文件，如需保留旧报告请提前备份
